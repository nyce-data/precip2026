# precip2026

This is the organizers' hub for the precipitation data risk workshop, held on Zoom on Tuesday and Wednesday, December 15 and 16, 2026, from 12:00 to 3:00 PM Eastern. AGU's Global Data Resilience Project and the New York Climate Exchange are convening it, in cooperation with the Keeling Curve Foundation.

The site is a single page, `index.html`, with no build step. It links to the team's Google Drive files and the sign-up form.

## Publish on GitHub Pages

1. Create the repository `nyce-data/precip2026` and add `index.html` and this README to the root.
2. Go to Settings > Pages and set Source to "Deploy from a branch", with `main` and `/ (root)`.
3. The site goes live at `https://nyce-data.github.io/precip2026/`.

## Access

A GitHub Pages site is public, even when the repository is private, unless the organization is on GitHub Enterprise Cloud. Anyone who has the URL can read this page. So the page carries no email addresses, scores, or dataset discussion. It only links to Google files, which keep their own sharing settings. The page also tells search engines not to index it.

## Updating

Edit `index.html` directly: each link is a plain `<a href>` in its section. When you change the page, update the "last updated" date in the footer.
